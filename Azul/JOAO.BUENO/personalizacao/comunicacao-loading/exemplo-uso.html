🛫 Azul Loading Banner - Demo

📋 Instruções

Este é um exemplo de como testar o modal de banner da Azul. O banner aparece automaticamente após carregar a página.

Para testar: Use os botões abaixo para simular diferentes cenários. Observe as mensagens progressivas que mudam conforme o loading.

🔧 Controle de Teste

Status atual da página:

URL: window.location.href
Banner deve aparecer automaticamente após carregar a página.

📱 Teste Responsivo

Use as ferramentas de desenvolvedor (F12) para testar diferentes tamanhos de tela:

  • Desktop: > 768px - Layout lado a lado
  • Tablet: 768px - Layout vertical
  • Mobile: < 480px - Layout compacto

⚙️ Configurações Atuais

Delay para exibir: Imediato
Tempo de exibição: 8 segundos
URL alvo: Qualquer página (temporariamente)
Imagem Desktop: https://i.imgur.com/MyN94BQ.png
Imagem Mobile: https://i.imgur.com/GAoQdi9.png
Mensagens Progressivas:
• 0%: "Estamos iniciando sua reserva..."
• 50%: "Quase lá... Estamos assegurando sua passagem."
• 75%: "Pronto para decolar! Estamos finalizando a etapa com segurança."
Título: "A um passo da viagem dos sonhos."
Compatibilidade: Adobe Target (sem template literals)

🎯 Eventos de Tracking

Abra o Console (F12) para ver os eventos de analytics sendo gerados:

azul_banner_show - Quando o banner aparece
azul_banner_hide - Quando o banner desaparece
