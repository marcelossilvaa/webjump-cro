🛫 Azul Loading Banner - Demo

📋 Instruções

Este banner da Azul foi modificado para detectar e substituir automaticamente qualquer elemento com a classe .loader que apareça na página apenas após clicar no botão "Ir para escolha de assentos" na URL /home/responsavel.

Como funciona:

  • O script verifica se está na URL /home/responsavel
  • Configura um listener no botão "Ir para escolha de assentos"
  • Quando o botão é clicado, ativa uma flag interna
  • Quando um loader aparece após o clique, substitui pelo banner da Azul
  • Outros loaders na mesma página são ignorados

Para testar: Use "Forçar Exibição do Banner" para ver o banner independente da URL, ou simule estar na página correta.

⚙️ Configurações Atuais

• Botão obrigatório: "Ir para escolha de assentos"
• Pré-carregamento: Imagem carregada antecipadamente

Tempo de exibição: 8 segundos
