# Padroes 333

## JavaScript em arquivos 333

- Evite ternarios quebrados em multiplas linhas. O parser antigo do Insider/JSHint pode acusar `W014: Misleading line break before '?'` quando a linha seguinte comeca com `?` ou `:`.
- Quando a expressao ternaria ficar longa, prefira `if/else` ou monte o texto em variaveis auxiliares.
- Nao confie apenas em `node --check` para esse caso: a sintaxe pode estar valida no Node e ainda gerar alerta no editor/Insider.

Exemplo a evitar:

```javascript
const regionText = count
  ? 'Entre ' + count + ' ' + label + ' da sua regiao'
  : 'Oferta da sua regiao';
```

Padrao recomendado:

```javascript
let regionText = 'Oferta da sua regiao';

if (count) {
  regionText = 'Entre ' + count + ' ' + label + ' da sua regiao';
}
```
